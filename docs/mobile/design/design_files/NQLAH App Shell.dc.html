2Unified app · 3 identities · provider-only contact
One download, one login. After sign-in the policy engine resolves the identity (Customer, Provider, Employed driver) and its permissions, and the same app mounts the matching shell. An owner-driver is a Provider whose only driver is themself, so they get the provider shell plus a light context switch. Updated in place in turn 1: 1c and 1d now show the provider only, 1o calls the provider's ops contact, 1i uses the new switch labels.
