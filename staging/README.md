# بيئة Staging — محجوزة (تُبنى بعد الإطلاق)

هذا المجلد **placeholder** محجوز لبيئة **Staging** المستقلّة التي ستُبنى **بعد الإطلاق**.

## السياق
للإطلاق السريع، اعتُمدت البيئة المنشورة حاليًا على `nqlah.online` كـ**Production** مباشرةً (كانت تُسمّى staging). انظر «استراتيجية الإطلاق» في [`docs/DEPLOYMENT.md`](../docs/DEPLOYMENT.md).

## الخطة لـStaging الجديدة (لاحقًا)
بيئة مستقلّة تمامًا عن الإنتاج (host + قاعدة بيانات + تخزين منفصلة)، تُستخدم لاختبار التحديثات قبل ترحيلها للإنتاج:

```
تطوير محلي  →  Staging (اختبار)  →  ترحيل ناجح  →  Production (حيّ)
```

عند بنائها:
- أنشئ تطبيق/بيئة Staging في Coolify بـ`NODE_ENV=staging`.
- قاعدة + Redis + تخزين منفصلة (لا مشاركة مع الإنتاج أبدًا).
- انسخ `.env.staging.example` → `.env.staging` واضبط القيم.
- فعّل بيانات الـseed التجريبية و«وضع OTP التجريبي» هنا (لا في الإنتاج).

> يُحدَّث هذا الملف بتفاصيل Staging الفعلية عند إنشائها. حتى ذلك الحين لا شيء هنا سوى الحجز.
